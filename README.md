# Todo React Avançado

Aplicação de lista de tarefas desenvolvida com React e Vite, permitindo adicionar, concluir, remover e filtrar tarefas.

## 🚀 Tecnologias utilizadas

- React
- JavaScript
- Vite
- Context API
- useContext
- useMemo
- React.memo
- Custom Hooks
- LocalStorage
- CSS responsivo

## ✨ Funcionalidades

- Adicionar novas tarefas.
- Marcar tarefas como concluídas.
- Remover tarefas.
- Filtrar tarefas por todas, pendentes ou concluídas.
- Salvar tarefas automaticamente no LocalStorage.
- Interface responsiva para dispositivos móveis.

## 💻 Como executar o projeto

1. Clone este repositório:
   ```bash
   git clone URL_DO_REPOSITORIO
   ```

2. Entre na pasta do projeto:
   ```bash
   cd todo-react-avancado
   ```

3. Instale as dependências:
   ```bash
   npm install
   ```

4. Inicie o servidor:
   ```bash
   npm run dev
   ```

5. Acesse o endereço indicado no terminal.

## 📚 Objetivo

Projeto desenvolvido como atividade prática do curso EBAC, com o objetivo de aplicar conceitos de React, gerenciamento de estado global, hooks, memoização e armazenamento local.
